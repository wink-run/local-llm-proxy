Outbound · WebSocket · OpenAI-compatible

闲置 Token 额度挂到公网
类 P2P，更接近 Token 自由

把套餐里用不完的 API token 额度（以及仅内网可达的上游、本机模型），通过 Agent 主动连出一台 VPS， 对外提供统一的 OpenAI 兼容接口。上游密钥只留在本机，服务端不收集；随时停掉 Agent，共享即结束。

快速开始 打开控制台

核心价值

不是再把流量绑死在某一家云厂商的固定 Endpoint；而是自愿接入、自带路由与上游，由代理只做鉴权与调度。

01 / SHARE

共享闲置 Token 额度

月度 / 订阅里未用完的调用量、内网网关背后的上游，或本机 Ollama，通过长连接「挂」到统一入口，团队或可信用户按需调用。

02 / MESH

多节点、类 P2P

每台机器自愿上线、声明模型列表；VPS 负责挑选 Worker 转发，请求从外网进、从你家出站。

03 / SAFE

无需暴露内网端口

内网 LLM 不对公网监听；只有 Agent 主动连出，穿透 NAT，降低暴露面。

架构一瞥

外部客户端使用 Bearer 用户 Key 访问 VPS；Worker 使用独立的 Worker Token 注册；上游 LLM 的 API Key 从不经过代理持久化。

  外部客户端  ──HTTP  Bearer USER_API_KEY──▶  ┌─────────────────────────────┐
                                           │  VPS · FastAPI :8000        │
                                           │  /v1/*   /admin/*   /ws/worker │
                                           └─────────────┬───────────────┘
                                                         │ WebSocket（内网主动发起）
                        ┌────────────────────────────────┼────────────────────────────────┐
                        │                                │                                │
                  ┌─────▼─────┐                    ┌─────▼─────┐                         │
                  │  llm-agent │                    │  llm-agent │   ...                   │
                  │  + 本地 LLM │                    │  + 本地 LLM │                         │
                  │  Bearer 仅在本机 │                    │            │                         │
                  └───────────┘                    └───────────┘                         │

隐私与控制权

设计目标：共享 token 调用路径的同时，不把上游密钥交给代理托管。

上游 API Key 不上云

--llm-token 仅保存在本机 Agent 配置，用于直连你的上游；向代理注册时只上传 Worker 鉴权、节点名与模型列表，协议不包含上游密钥。

随时停止共享

停止 Agent（如 Ctrl+C）或断网即不再承接请求，无需在服务端「解绑」。用户侧调用 VPS 所需的 Key 由管理后台签发（存于服务端数据库），与上游密钥是两回事。

快速开始

以下为常用命令摘要；完整变量说明与本地开发见仓库内 README.md。

VPS · Docker

复制 .env.example 为 .env，填写 WORKER_TOKEN、ADMIN_KEY 后：

cp .env.example .env
docker compose up -d --build
# 默认端口 8000，详见 README

内网 · Agent

注册一次后 start 保持在线：

cd agent && pip install -r requirements.txt
python agent.py register \
  --server "ws://你的VPS:8000/ws/worker" \
  --token "$WORKER_TOKEN" \
  --models "模型A,模型B" \
  --llm-url "http://localhost:11434"
python agent.py start

调用接口：GET /v1/models、POST /v1/chat/completions，请求头 Authorization: Bearer <后台创建的 Key>。
