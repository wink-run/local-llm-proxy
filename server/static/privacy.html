Token Bank 隐私政策

生效日期：2026-07-21
适用产品：Token Bank（Bundle ID：run.wink.tokenbank.app）及同品牌桌面 / CLI 客户端
运营方：lee wink / wink-run
联系：GitHub Issues

一、原则

Token Bank 是运行在你电脑上的本地 AI 网关与 Token 管家。我们坚持：本地优先；仅在你登录或启用云端 / 社区分享功能时上云；上游 API Key 原文不上云；不向广告商或数据经纪商出售个人信息。

二、我们可能处理的信息

仅本机（默认不上传）：上游 API Key / OAuth 令牌、网关与路由配置、本地用量与 Trace、工作画像与已纳管资源等。

登录后为提供功能所必需时：账户标识与会话令牌；设备 ID / 名称 / 平台 / 应用版本与心跳；用量统计摘要（调用量、Token、费用估算、排行等，非完整对话原文）；订阅与配置摘要或指纹（凭证原文不上报）；社区分享节点元数据（如模型名，不含上游 Key）；必要的诊断信息。

我们不会故意收集：以训练自有大模型为目的的完整对话正文；通讯录、相册、精确持续定位、麦克风 / 摄像头等无关内容。

你主动选择的第三方模型服务商或社区分享节点，按其自身隐私政策处理请求内容。

三、使用目的

用于提供与改进纳管、Trace、路由、盘点、推荐、社区分享等功能；多设备同步；安全与防滥用；故障排查；以及履行法律义务。不用于与产品无关的第三方广告定向。

四、共享与跨境

我们不出售个人信息。云端托管方仅可在提供服务所必需范围内处理数据。第三方模型 / 节点独立运营。依法可能披露。若你使用境外节点或上游服务，数据可能跨境，请自行评估。

五、保存与安全

本机数据由你控制。云端数据在账号存续期间为提供服务而保存；你可申请注销并删除云端账户数据（法律另有规定除外）。我们采取合理安全措施，但无法保证绝对安全。

六、你的权利

在适用法律下，你可访问、更正云端信息；退出登录或关闭同步 / 分享；删除本机数据或申请删除云端数据。请通过文首渠道联系我们。

七、儿童

本产品不以儿童为服务对象。若发现误收集儿童个人信息，将尽快删除。

八、更新

我们可能更新本政策，并通过应用内提示、版本说明或项目主页告知重大变更。

Token Bank Privacy Policy

Effective date: 2026-07-21
Product: Token Bank (Bundle ID run.wink.tokenbank.app) and related clients
Operator: lee wink / wink-run
Contact: GitHub Issues

1. Principles

Token Bank is a local AI gateway. We are local-first; upload only when you sign in or enable cloud / community sharing; never upload upstream API key plaintext to our servers; and do not sell personal data.

2. Data we may process

On-device by default: API keys/tokens, gateway config, local usage/traces, portraits and managed resources.

After sign-in, as needed: account identifiers and session tokens; device ID/name/platform/version and heartbeats; aggregated usage snapshots (not full chat transcripts); subscription/config summaries or fingerprints; community-sharing node metadata without upstream keys; limited diagnostics.

Third-party model providers and community-sharing nodes you choose are governed by their own policies.

3. Use

To provide and improve the product, multi-device sync, security, troubleshooting, and legal compliance—not unrelated third-party ad targeting.

4. Sharing

No sale of personal data. Processors act under instruction; independent operators apply their own terms; disclosure may be required by law. Cross-border transfers may occur if you use overseas endpoints.

5. Retention & security

On-device data is under your control. Cloud data is kept while the account is active; you may request deletion subject to legal exceptions. We use reasonable safeguards.

6. Your choices

Access/correct cloud data; sign out or disable sync/sharing; delete local data; request cloud account deletion via the contact above.

7. Children

Not directed at children. Inadvertently collected children’s data will be deleted.

8. Changes

We may update this policy and will provide notice of material changes.
