# App Store Connect 文案（中 / 英）

在 App Store Connect 左上角语言切换分别粘贴。  
字数均在限额内：推广文本 ≤170 · 描述 ≤4000 · 关键词 ≤100。

---

## 简体中文

### 推广文本（170）

```
个人AI中枢：一键纳管 Claude Code / Cursor / Codex，用量可追溯，智能路由省 Token，闲置额度还能赚积分。
```

### 描述（4000）

```
Token Bank 是你的个人 AI 中枢与 Token 管家——把常用 AI 工具统一接到本地网关，用量看清楚、花得更省，闲置算力还能换成社区积分。

【你可能遇到的问题】
• 订了多家 LLM，却说不清每天 Token 花在哪
• 免费额度没用完，付费账单却一直涨
• 本机已有 Ollama，工具仍在直连接口
• 月末套餐额度清零，白白浪费

【核心能力】
• 一键纳管：Claude Code、Codex、Cursor、Gemini CLI 等，尽量不改客户端习惯
• 全链路 Trace：网关实时记账 + 会话补录，调用、模型、耗时、费用可查
• 无损换模：客户端仍显示原生模型名，网关透明路由到本地或第三方模型
• 智能路由：本地源（Ollama / 免费 API / 订阅 / 按量）优先，必要时走社区 P2P
• CLI 多账号：按工作目录分发 Claude / Codex 实例，额度分账号统计
• 资源中枢：MCP / Skill / Prompt / Agent 推荐与投射
• 盘点与订阅：按应用、供给源、模型、费用、设备、时间切片；多设备可云端汇总
• 托盘常驻：网关状态与今日用量一键查看

【适合谁】
同时使用多种 AI 编程 / Agent 工具、希望控制成本与可观测用量的开发者与团队。

【说明】
本应用在本地运行网关服务。API Key 默认保存在本机。请遵守所在地法律法规及上游服务条款。
```

### 关键词（100）

```
AI,Token,LLM,Claude,Cursor,Codex,网关,代理,用量,路由,Ollama,MCP,智能体
```

## English

### Promotional Text (170)

```
Personal AI hub: onboard Claude Code, Cursor & Codex in one click. Trace usage, smart-route to cut costs, earn credits from idle quota.
```

### Description (4000)

```
Token Bank is your personal AI hub and token manager. It sits between your AI tools and LLM providers as a local gateway—so you can see where tokens go, spend less, and turn idle capacity into community credits.

WHAT IT SOLVES
• Multiple LLM subscriptions with no clear view of daily usage
• Free quotas left unused while paid bills keep rising
• Local Ollama running, but tools still call paid APIs
• Month-end plan credits that expire unused

CORE FEATURES
• One-click onboarding for Claude Code, Codex, Cursor, Gemini CLI, and more—with minimal client changes
• Full trace: live gateway accounting plus session import—calls, models, latency, and cost in one place
• Seamless model swap: keep native model names in the client while the gateway routes to local or third-party models
• Smart routing: prefer local sources (Ollama / free APIs / subscriptions / pay-as-you-go), fall back to community P2P when needed
• Multi-account CLI: dispatch Claude / Codex instances by working directory with per-account quotas
• Resource hub: MCP / Skill / Prompt / Agent catalog with projection controls
• Usage & subscriptions: slice by app, provider, model, cost, device, and time; optional multi-device cloud merge
• Menu bar tray for gateway status and today’s usage

WHO IT’S FOR
Developers and teams who juggle multiple AI coding / agent tools and want cost control plus observability.

NOTES
Token Bank runs a local gateway on your Mac. API keys stay on your device by default. Please follow local laws and upstream provider terms.
```

### Keywords (100)

```
AI,Token,LLM,Claude,Cursor,Codex,gateway,proxy,usage,routing,Ollama,MCP,agent
```

## 操作提示

1. 语言 = **简体中文**：粘贴上面「简体中文」三块  
2. 右上角 / 左侧加语言 → 添加 **English (U.S.)**，粘贴「English」三块  
3. 两种语言都要各自上传截图（可先同一套，后续再区分）
