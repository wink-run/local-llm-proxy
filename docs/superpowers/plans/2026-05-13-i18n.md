# i18n zh/en Toggle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Chinese/English language switching to the sidebar nav labels and Config (Settings) page, with the toggle living in the Settings page.

**Architecture:** A `LangProvider` (mirrors the existing `ThemeProvider` in `src/store/theme.jsx`) stores `'zh'`/`'en'` in localStorage and exposes a `t(key)` translation function via React context. A single `src/i18n.js` file holds both locale dictionaries. Only the Sidebar and Config page consume `t()` — all other pages remain in Chinese.

**Tech Stack:** React 18, React Context, localStorage, Tailwind CSS (existing stack — zero new dependencies)

### Task 2: LangProvider and useLang hook (`src/store/lang.jsx`)

**Files:**
- Create: `client/src/store/lang.jsx`

- [ ] **Step 1: Create the provider file**

```jsx
import React, { createContext, useContext, useState } from 'react';
import { makeT } from '../i18n';

const LangContext = createContext(null);

export function LangProvider({ children }) {
  const [lang, setLangState] = useState(
    () => localStorage.getItem('lang') || 'zh'
  );

  function setLang(l) {
    localStorage.setItem('lang', l);
    setLangState(l);
  }

  const t = makeT(lang);

  return (
    <LangContext.Provider value={{ lang, setLang, t }}>
      {children}
    </LangContext.Provider>
  );
}

export function useLang() {
  return useContext(LangContext);
}
```

```jsx
const LANGS = [
  { value: 'zh', labelKey: 'lang.zh' },
  { value: 'en', labelKey: 'lang.en' },
];

function LangSelector() {
  const { lang, setLang, t } = useLang();
  return (
    <div className="flex rounded-lg overflow-hidden border border-gray-200 dark:border-gray-700">
      {LANGS.map((l) => (
        <button
          key={l.value}
          onClick={() => setLang(l.value)}
          className={`flex-1 py-2 text-sm font-medium transition-colors ${
            lang === l.value
              ? 'bg-blue-600 text-white'
              : 'bg-white dark:bg-gray-800 text-gray-600 dark:text-gray-400 hover:bg-gray-100 dark:hover:bg-gray-700'
          }`}
        >
          {t(l.labelKey)}
        </button>
      ))}
    </div>
  );
}
```
