## 〇、先躲开的坑（创意否决权）

笔记软件老路 = 藏而不用 + 整理快感 + 普通用户无感 + 宣传只能晒「我有很多」。  
凡是让用户**先建库再受益**的点子，脑暴阶段直接否决——详见反陷阱文档。

**普通用户 15 秒故事（唯一主叙事）：**

> 装上 Token Bank，你的 Cursor / Claude 马上多会一件事。不用建库。武将与兵器闲了还能出租换积分。

**库的合法形状：** 武将库（智能体）+ 兵器库（Skill/Prompt）——**自用或出租**，不是笔记收藏。

## 一、隐喻翻转：从「收藏夹」到「自动打进工资卡的能力」

| 旧心智 | 新心智 | 眼前一亮点 |
|---|---|---|
| 我收藏了很多 Prompt | 我**启用**了一项能力，下句对话就生效 | CTA「启用到 Claude Code」不是「加入库」 |
| 投射到 Agent | 工资卡自动扣款（能力自动出现在 Agent 里） | 启用包 = 入库∧投射∧口令 |
| 闲置 Skill | 不通货的钱：销户或拿去赚利息 | 休眠公函 → 捐出换积分 |
| 社区分享算力 | 活期，夜间自动结息 | 托盘「昨夜 +128」——与内容能力同一「出手」语言 |
| 工作画像 | 猜你今天要办的事 | 场景货架，不按 Prompt/Skill 类型逛商场 |

**一句话创意锚点（已改）：**

> 不是经营一座要整理的金库，而是让能力自动出现在你正在用的 AI 里。

## 1.5 使用时主隐喻：武将库 · 主公点将（已升格为正式设计）

**武将 = 资产中的智能体（assistant）**；Skill / Prompt 是兵书，不是将。  
出战 **≠** 网关注入，**≠** 模型场景路由（路由只管算力）。

- 武将不能自己冲上去；**主公（Claude Code / Cursor）点将才出战**  
- 钥匙 = MCP（`tb_list_generals` / `tb_suggest_general` / `tb_activate_general`）  
- 激活返回智能体 soul + 绑定 prompt/skill 文本；不改 tool schema  
- 早期主路径 = 用户喊智能体名显式点将；编排派发仍走 `tb_dispatch_agent`  

详见 [武将库 MCP 点将设计](./2026-07-25-general-roster-mcp-design.md)。

## 二、十个「眼前一亮」概念（可单点落地）

### 1. 开库仪式 · Weekly Vault Open

每周第一次进入「资源」，不是列表，而是一次 **3 秒开库**：

- 暗色金库门缝透出铜光 → 门拉开  
- 中央大数字：**本周 AI 净资产股息 86 次命中**  
- 副行：活期（算力）+128 积分 · 生产资本命中 86 · 休眠 14  
- 然后才落入日常分层视图  

**为什么亮：** 把「管理页」变成「对账时刻」，认知瞬间建立。  
**慎用：** 每天都播会烦 → 仅每周首次 / 用户可跳过。

---

### 2. 资产存折 · Passbook Timeline

每条资产点开不是 Markdown 预览，而是一页 **存折**：

```
代码审查 · Prompt
────────────────────────
07-22  Claude Code   命中   +1 息
07-23  Cursor        命中   +1 息
07-24  （休眠日）
07-25  Claude Code   命中   +1 息 · 关联会话 →
────────────────────────
累计息票  47    已授权 Agent  2
```

右侧盖「戳记」：高频 / 生息中 / 休眠。  
**视觉：** 轻微纸纹 + 等宽数字 + 一枚铜印，不做卡片堆。

---

### 3. 制卡投射 · Agent Debit Card

「投射」改名为用户能懂的动作：**发卡**。

- 选中 Prompt → 抽出一张小卡（印资产名）  
- 拖到 / 点选 Claude Code → 卡面浮现该 Agent 头像水印  
- 文案：「已授权 Claude Code 从此卡扣款取用」  

取消投射 = 挂失 / 销卡。  
**为什么亮：** 「投射」是内部词；「发卡」一秒懂权限模型。

---

### 4. 包浆工具墙 · Patina Workshop

「我的资产」不要整齐 SaaS 网格，做成 **工位工具墙**：

- 常用 Skill 像挂久的扳手——边缘微磨损、色泽更深（包浆）  
- 从未用过的像塑封新工具——发青、轻、无痕迹  
- 命中一次，工具轻震一下再归位  

**为什么亮：** 价值被「用旧」证明，而不是被数字证明；极客会心动。  
**实现：** CSS 噪点 + 使用次数映射饱和度/阴影，零 3D。

---

### 5. 今日息票 · Session Receipt

Agent 会话结束（或 TB 检测到资产命中）后，右下角滑出一张 **短收据**：

```
TOKEN BANK  息票
────────────────
命中   代码审查
通道   Claude Code
估计   少走 2 轮空转
息票   #0847
────────────────
[看存折]  [再投一张]
```

可分享为故事图（复用画像海报气质，但更像小票）。  
**为什么亮：** 每次使用都完成一次「价值教育」，无需 onboarding。

---

### 6. 持仓星图 · Portrait Constellation

工作画像不再是标签云，而是 **夜空星图**：

- 每条高契合资产 = 一颗星，亮度 = 近 7 日命中  
- 用途簇 = 星座连线（开发座、写作座…）  
- 沉睡资产 = 暗星，点击可「唤醒（重投）」或「陨落（清理）」  

从推荐页「为你推荐」变成「补全你的星座缺角」。  
**为什么亮：** 画像第一次变得可记忆、可炫耀、可截图。

---

### 7. 金库 ATM · Tray Withdraw

托盘常驻增加 **ATM 快捷槽**（3 个最近生息资产）：

- 单击「提取到剪贴板 / 提取用法口令」  
- 或「推到当前前台 Agent」（若该 Agent 已发卡）  

场景：你在 Cursor 里卡住，抬手从托盘抽一张「调试口令」。  
**为什么亮：** 资产离开「资源页」也能用——银行有 ATM，金库不能只有柜台。

---

### 8. 复利年轮 · Compound Rings

资产图标外圈画 **年轮**：

- 每成功命中一圈极细弧  
- 满月 = 里程碑（10 / 50 / 100），触发一次微光  

列表扫一眼就知道谁是「老本营资产」。  
比进度条更有收藏感，又不如徽章体系廉价。

---

### 9. 血缘谱系 · Asset Genealogy

从 Trace 自动长出：

`某次会话长指令 → 沉淀为 Prompt A → 分叉出 A'（团队向）→ 被 3 个 Agent 持卡`

用横向谱系而不是文件夹树。  
**为什么亮：** 用户第一次意识到「我的方法论在繁殖」——这是真正的资产感。

---

### 10. 休眠公函 · Dormant Notice

沉睡资产不配红色「危险」警示，而配一封 **短公函**：

> 敬启者：您名下「会议纪要」等 6 笔生产资本已逾 30 日无扣款记录。  
> 建议：重新发卡 / 归档入冷库 / 捐入社区目录换积分。  
> —— Token Bank 托管部

语气轻微戏谑 + 银行仪式感，比「清理垃圾」更尊重用户过去的投入。

## 三、多角度雷达（创意筛子）

### A. 行为心理

- **禀赋效应**：先让用户看见「已生息」，舍不得乱删，才会认真投/清  
- **损失框架**：不说「清理 14 个」，说「14 笔资本正在贬值（0 息）」  
- **变量奖励**：不是每天弹窗，而是「意外息票」（连击命中时）  
- **身份信号**：海报/星图让人愿意对外说「我有一套 AI 持仓」

### B. 时间尺度

| 尺度 | 体验 |
|---|---|
| 秒 | 命中震动 / 年轮 +1 |
| 次 | 息票收据 |
| 日 | 托盘「昨夜利息」 |
| 周 | 开库仪式 |
| 季 | 持仓再平衡（画像变了） |

### C. 角色

| 角色 | 亮点不同 |
|---|---|
| 个人黑客 | 包浆工具墙、ATM、谱系 |
| 写作/知识工作者 | 存折、息票、星图 |
| 小团队 | 发卡权限、谱系分叉、圈子「联合账户」 |
| 贡献者 | 活期结息、捐资产换积分 |

### D. 竞争锚点（借势但不照搬）

- 银行 App 的「昨日收益」→ 昨夜利息  
- 照片 App 的「回忆」→ 开库周报  
- 游戏装备的「磨损/淬炼」→ 包浆与年轮  
- Spotify 年终告白 → 画像星图年报  
- 硬件工具墙 → 资源主视图  

### E. 反模式（头脑风暴时主动杀掉）

- 紫渐变能量石「价值分 87」  
- 勋章墙 / 等级 VIP  
- 首屏塞满统计卡片  
- 再造一个「资产市场」二级 App  
- 教育弹窗多于一次真实息票

## 四、视觉方向提案（创意向，非最终 Design System）

**代号：Midnight Ledger（午夜账本）**

- 底：深墨绿偏黑 `#0B1512`，不是纯黑科技风  
- 光：老化黄铜 `#C4A574` 做数字与印章  
- 纸：账本内页用暖灰纸纹 `#E7E0D5`（仅存折/收据表面，不铺全站）  
- 字：展示用有衬线（如 Fraunces），数字用等宽（JetBrains Mono）  
- 动：门缝、盖章、年轮生长——每种最多 400ms，克制  

刻意避开：紫靛渐变、奶油陶土、大报排版、玻璃拟态光晕堆叠。

**氛围一句：** 私人银行的夜柜台 × 用旧的工具墙。

## 五、创意组合拳（推荐叙事线 · 已防囤积改写）

对外发布故事（普通用户）：

1. **动作** — 场景货架「启用到 Cursor」（当场会用）  
2. **反馈** — 今日息票 / 前后对比（认知 + 宣传弹药）  
3. **出口** — 用不上的休眠公函 → 捐积分；算力过夜结息  

对内进阶彩蛋（勿当获客主视觉）：

- 出手周报（原开库，强调命中不是库存）  
- 包浆 / 年轮（只绑命中）  
- 存折 / 星图（详情与年终分享）

## 六、疯狂一点但值得记一笔的点子

1. **资产保险柜物理键**：按住托盘图标 1s，像保险柜转盘，弹出今日 Top3 生息资产  
2. **双人联名卡**：圈子内两人对同一 Prompt「联名发卡」，谱系显示共有  
3. **贬值倒计时沙漏**：套餐额度月末清零前，沙漏与「可捐出换积分」绑定  
4. **幽灵命中**：Agent 自己选中了某 Prompt，息票上印「自主扣款」——强化 MCP 路径正确性  
5. **金库访客模式**：分享只读星图链接（无正文），用于社交炫耀但不泄露 Prompt  
6. **利息再投资**：一键把本周积分「再投资」成社区目录里一条推荐资产的纳管

## 八、给设计与研发的判据

评审任何方案时只问四句：

1. **普通用户能否不进资源库就完成启用并命中？**（反笔记陷阱）  
2. **这屏拿去宣传，秀的是变强结果还是仓库？**（可传播）  
3. **CTA 是否通向 48h 内可验证的命中？**（反囤积）  
4. **离开导航栏，还像 Token Bank 的「用的明白 / 闲置赚钱」吗？**（品牌）  

做不到就还是笔记软件换皮——杀掉重来。
