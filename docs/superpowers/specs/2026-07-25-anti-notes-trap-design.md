## 1. 陷阱长什么样

笔记软件（及书签 / 稍后读 / Prompt 收藏夹）的老路：

```
发现 → 收藏进库 → 偶尔整理标签 → 几乎不再打开 → 库越大越心虚
         ↑________________「我有很多资产」的幻觉 ________↓
```

对 Token Bank 的映射风险：

| 笔记软件 | 我们若走老路 |
|---|---|
| 收藏一篇文章 | 纳管一条 Skill / Prompt |
| 建笔记本 / 标签 | 资源页分类、用途芯片、星图收藏 |
| 「知识管理」宣传 | 「AI 资产库 / 私人金库」宣传 |
| 重度用户整理快感 | 极客沉迷发卡 / 存折 / 包浆 |
| 普通用户无感流失 | 普通用户觉得「又一个要打理的库」 |

**判据：** 若用户主路径变成「进资源页整理」，而不是「Agent 当场变强」，就已经掉进陷阱。

## 2. 硬原则（写进评审，不可破）

### P0 · 用，是唯一成功定义

- 成功 ≠ 纳管数、库存数、标签完整度  
- 成功 = **7 日内至少 1 次真实命中**（Agent 会话里用上了）  
- 任何功能若只增加「藏」而不强制通向「用」，砍掉或降级  

### P1 · 普通用户可以零管理

- 默认路径：**选能力 → 自动挂到常用 Agent → 下一次对话直接生效**  
- 「资源 / 金库 / 分层治理」是**进阶后门**，不是首页故事  
- 没进过资源页的用户，也能完整获得价值  

### P2 · 宣传卖结果，不卖仓库

| 禁止对外说 | 对外只说 |
|---|---|
| 管理你的 AI 资产 / Prompt 库 | 让 Claude / Cursor **立刻会**代码审查、写周报… |
| 私人 AI 金库 / 知识中枢 | 一键让 AI **更懂你的活** |
| 收藏 100+ Skill | **今天少扯皮 2 轮**；昨夜闲置算力赚了积分 |

落地页、应用商店、海报：**先秀「Agent 变强前后」**，再提背后有资源与路由。  
金库视觉可以做品牌彩蛋，**不能当获客主视觉**。

### P3 · 收藏必须附带「第一次使用」

纳管按钮的语义从「加入库」改为 **「启用」**：

```
点「启用」
  → 写入个人库（可逆）
  → 默认投射到主 Agent / 当前纳管 Agent（可改）
  → 给出一句可复制口令 或 自动打开一次试跑
  → 48h 内无命中 → 轻推「还没用上，要换场景 / 换 Agent / 撤销」
```

**禁止**出现「已收藏」且 0 投射、0 用法提示的终态。

### P4 · 库存默认受惩罚，使用受奖励

- 未命中的条目视觉变轻、排序沉底（不是徽章墙越藏越光荣）  
- 沉睡自动进入冷库 / 建议捐出换积分（流通 > 占坑）  
- 包浆 / 年轮 **只奖励命中**，不奖励纳管天数  
- 开库周报若库存↑命中↓ → 文案走「资本闲置」，不是「库更丰富了」  

### P5 · 银行隐喻只保留「钱必须出去工作」

危险隐喻：保险箱、珍藏、存折收藏癖。  
安全隐喻：**工资卡自动扣款、股息来自出手、休眠要销户**。

一句话改写：

> ~~经营一座私人金库（容易变成囤）~~  
> **让能力自动出现在你正在用的 AI 里——用不上的，系统帮你清掉或拿去赚积分。**

## 3. 普通用户主路径（获客友好）

普通用户心智只有三步，没有「资产」一词：

```
① 我今天要干什么？     （选场景 / 或由画像猜）
② 一键让 AI 会这个      （启用 = 投射+口令）
③ 下次直接变强了        （息票证明「有用」）
```

### 信息架构（防陷阱）

```
对外 / 新用户
├─ 网关纳管 Agent          ← 已有，继续做主入口
├─ 「让 AI 更强」能力商店   ← 原「为你推荐」升格为主故事
│    卡片 CTA =「启用到 Claude Code」不是「纳管」
└─ 用完息票 / 托盘一句反馈

进阶（藏得深）
└─ 资源库 / 分层 / 存折 / 清理 / 捐出
   （设置或「高级」入口，不抢首屏）
```

**宣传截图优先级：**  
能力启用后的 Agent 对话差 → 息票小票 → 盘点「省了/赚了」→（很后才）资源库。

## 4. 产品机制：逼「藏」变成「用」

### 4.1 启用包（Adoption Bundle）——取代裸纳管

一次点击打包：

1. 入库  
2. 投射到默认 Agent（必选，可改多选）  
3. 同步 MCP / Skill（已有能力）  
4. 展示 **开口令**（一句话用法）  
5. 可选：生成一条「试跑」任务到游乐场  

未完成 2+4，不算启用成功（UI 保持进行中）。

### 4.2 场景货架，不要仓库货架

首页推荐按 **「我要完成的事」** 排，不按资源类型排：

- 审查这段代码  
- 把会议纪要变成待办  
- 用本地模型省额度  
- 让闲置 GPU 过夜赚积分  

点进去才展开背后是 Prompt / Skill / MCP。  
普通用户买的是**事**，极客才买类型。

### 4.3 命中或退场（Hit-or-Exit）

| 状态 | 系统行为 |
|---|---|
| 启用后 48h 0 命中 | 推一口令 / 换 Agent；提供「撤销启用」 |
| 7 日 0 命中 | 取消默认投射（可恢复），标「未打穿」 |
| 30 日 0 命中 | 休眠公函：重启用 / 冷藏 / 捐出换积分 |
| 持续命中 | 息票 + 年轮；可问「要分享到圈子吗」 |

库的自然体积被机制压住——**流通率**才是健康指标。

### 4.4 反笔记指标（North Star 旁路）

| 看 | 不看（或当负向） |
|---|---|
| 启用→首次命中转化率 | 纳管总数 |
| 7 日命中率 / 已启用数 | 标签覆盖率 |
| 零管理用户（从未打开资源库）的业务成功率 | 资源页停留时长 |
| 对外分享的是「变强结果」占比 | 库存截图分享 |

若「资源页 DAU」远高于「资产命中 UV」→ 产品在诱导整理，立即纠偏。

## 5. 对先前创意的修正（哪些留 / 哪些削）

| 概念 | 裁决 | 原因 |
|---|---|---|
| 今日息票 | **加强，主路径** | 证明「用了」，非「藏了」 |
| 制卡投射 | **留，但文案改「启用到…」** | 动作通向使用 |
| 场景货架 / 能力商店 | **新主故事** | 普通用户可传播 |
| 包浆 / 年轮 | **仅绑定命中** | 防变成收藏皮肤 |
| 开库周报 | **改成「出手周报」** | 强调命中与股息，淡化库存 |
| 存折时间线 | 进阶详情 | 勿当首页 |
| 持仓星图 | 年终/分享彩蛋 | **禁止当日常管理主界面**（极易变收藏秀） |
| 金库门动画 | 品牌彩蛋 | **禁止当获客主视觉** |
| 大而全资源库导航 | **降级** | 笔记软件形状本身 |

## 6. 传播话术（普通用户向）

**15 秒能懂：**

> 装上 Token Bank，你的 Cursor / Claude 马上多会一件事。  
> 不用建库，不用整理。用不上的，自动收起来还能换积分。

**禁止出现在首屏的词：** 资产库、知识库、纳管中心、Prompt 管理、第二大脑。

**可以出现的词：** 立刻会、少扯皮、一键启用、今晚赚积分、用的明白。

前后对比素材（宣传唯一主素材）：

```
Before: 用户跟 AI 来回 6 轮才审完 PR
After:  启用「代码审查」后，一句「按代码审查过一下」→ 2 轮结束 + 息票
```

## 7. 与「价值闭环」文档的关系

闭环仍成立，但顺序改写为：

```
当场启用并命中  →  看见息票（认知）  →  偶尔治理沉睡（管理）  →  捐出/算力变现
     ↑______________ 普通用户可以永远停在前两步 ______________↓
```

管理是为了**提高命中密度**，不是为了供养一座库。

---

## 8. 一句话红线

> **Token Bank 卖的是「正在用的 AI 突然会干活」，不是「又一个可收藏的笔记库」。**  
> 凡是让普通用户先整理再受益的设计，视为回归老路，一律打回。
